# 👋 Start here

This repo is a **template** for automated mobile app testing (Appium + Mocha,
running on BrowserStack, reporting to TestRail, triggered from Bitbucket). You
clone it, point it at *your* app, and run tests in the cloud — no local install
needed to run.

Pick your path:

### 🤖 With an AI (recommended)
Open this folder in an AI coding tool (e.g. Claude) and say:

> **"Help me set up automated tests for my app."**

The AI follows [`CLAUDE.md`](CLAUDE.md) and walks you through everything, one
step at a time — reading your app, mapping its screens, and writing the tests
with you.

### 🧑 On your own
Follow [`README.md`](README.md) top to bottom. Every AI step has a manual
equivalent there.

---

**New to all of this?** That's expected. The README assumes zero prior knowledge
of Appium, pipelines, BrowserStack or TestRail and defines every term the first
time it appears.
