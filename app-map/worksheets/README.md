# Section design worksheets

Copy `manual/TEST-CASE-WORKSHEET.md` into this directory once per section:

```text
app-map/worksheets/android-profile.md
app-map/worksheets/ios-profile.md
app-map/worksheets/shared-account-setup.md
```

Use `shared-` only when the preconditions, case mapping, and intended behaviour
are genuinely the same on both platforms. Platform selectors still belong in
the worksheet's separate Android and iOS columns.

These completed worksheets are tracked design evidence. Do not include secrets,
customer data, unapproved source excerpts, screenshots, or raw page source.
